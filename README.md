
# Learn git and GitHub Basics

A beginner-friendly Git and GitHub syllabus for Android, Windows,
macOS and Linux users.

## Features

- Device-specific setup guides
- Git command reference
- Step-by-step VCS syllabus
- Progress checklist
- Interactive revision quiz
- Written questions and answers
- Responsive dark theme

## How to use

1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Select your operating system.
4. Study the syllabus and practise the commands.
5. Complete the quiz and practical exercises.

No framework or build process is required.

## Project structure

- `index.html`: main syllabus
- `style.css`: visual design
- `script.js`: progress tracking and quiz
- `pages/`: device-specific guides

## Learning objective

Understand version control, Git repositories, commits, branches,
remotes, forks, Pull Requests, collaboration and safe recovery.
