Git on Windows

Install Git for Windows from the official Git website.

1. Open Git Bash or PowerShell

Git Bash provides a Unix-like shell. PowerShell is the Windows command shell.

2. Check installation

git --version
git config --global --list

3. Configure Git

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

4. Navigate folders

In PowerShell:

Get-Location
Get-ChildItem
Set-Location Documents
New-Item -ItemType Directory practice

In Git Bash, you can use:

pwd
ls -a
cd ~/Documents
mkdir practice

5. Use Git

git clone https://github.com/OWNER/REPO.git
cd REPO
git status
git switch -c feature/my-change
git add .
git commit -m "Describe my changes"
git push -u origin feature/my-change
The Git commands are the same as on Android. Folder navigation differs depending on whether you use PowerShell or Git Bash.
