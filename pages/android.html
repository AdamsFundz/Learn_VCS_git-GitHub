Git on Android

Use Termux to run Git commands directly on your phone.

1. Install Git

pkg update
pkg upgrade
pkg install git
git --version

2. Configure Git

git config --global user.name "AdamsFundz"
git config --global user.email "your-email@example.com"
git config --global --list

3. Navigate your folders

pwd
ls -a
cd ~/projects
mkdir practice
cd practice

4. Start or download a repository

git init

# Or clone an existing project:
git clone https://github.com/OWNER/REPO.git
cd REPO

5. Daily workflow

git status
git diff
git add .
git diff --cached
git commit -m "Describe my changes"
git push
Run git push only after your branch has a remote and the required authentication is configured. The first push may need git push -u origin BRANCH.

Remember

  • Termux commands are case-sensitive.
  • Keep working in the original repository folder.
  • Copying a project into another folder does not automatically sync the copies.
