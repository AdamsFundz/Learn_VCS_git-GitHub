Git on Linux

These installation examples are for Ubuntu and Debian-based systems.

1. Install Git

sudo apt update
sudo apt install git
git --version

2. Configure Git

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global --list

3. Navigate folders

pwd
ls -a
cd ~/Documents
mkdir practice

4. Clone and contribute

git clone https://github.com/OWNER/REPO.git
cd REPO
git switch -c feature/my-change
git status
git add .
git commit -m "Describe my changes"
git push -u origin feature/my-change
Other Linux distributions may use different package managers. For example, Fedora uses DNF. The Git workflow remains the same.
