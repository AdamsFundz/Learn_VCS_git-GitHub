Git on macOS

1. Open Terminal

Open Applications → Utilities → Terminal.

2. Check Git

git --version

If Git is missing, macOS may offer Command Line Tools. Follow the installation prompt. Alternatively, use the official Git for macOS instructions.

3. Configure Git

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

4. Navigate folders

pwd
ls -a
cd ~/Documents
mkdir practice

5. Work with a repository

git clone https://github.com/OWNER/REPO.git
cd REPO
git status
git switch -c feature/my-change
git add .
git commit -m "Describe my changes"
git push -u origin feature/my-change
macOS Terminal uses a Unix-like shell. The everyday Git workflow is essentially the same as on Linux and Termux.
