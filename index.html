STEP 02

Understand VCS first

What is VCS?

A Version Control System records changes to files over time. It helps you track edits, compare versions and collaborate without losing control of your work.

Git vs GitHub

Git tracks changes. GitHub hosts Git repositories online and provides tools for pull requests, issues and code reviews.

STEP 04

Useful command reference

Replace placeholders such as BRANCH or URL with your actual values. Do not type the placeholder word itself.

CommandMeaning
git statusShows the current branch and file state.
git add FILEStages a selected file's changes.
git add .Stages changes beneath the current directory; inspect first.
git commit -m "MESSAGE"Records staged changes with a message. -m supplies the message.
git diffShows changes not yet staged.
git diff --cachedShows changes already staged.
git log --onelineDisplays compact commit history.
git switch -c BRANCHCreates and switches to a new branch. -c means create.
git remote -vShows remote names and URLs.
git fetch originDownloads remote updates without automatically merging them.
git pullFetches and integrates updates into the current branch.
git push -u origin BRANCHPushes the branch and sets its upstream tracking branch.
git restore --staged FILEUnstages a file while keeping its edits.
git revert COMMITCreates a new commit that reverses an earlier commit.
git help COMMANDOpens help for a Git command.
Don't run git reset --hard, git clean -fd or git push --force casually. These can destroy work or rewrite shared history. Understand the situation and make a backup first.

STEP 06

Written Q&A

What is the difference between Git and GitHub?

Git is the version-control tool. GitHub hosts repositories online and supports collaboration features.

What is the difference between a commit and a push?

A commit saves staged changes to local Git history. A push sends commits to a remote repository.

What is a branch?

A separate line of development where you can make changes without directly changing another branch.

Why should I inspect git diff --cached?

It lets you check exactly which staged changes will be included in your next commit.

What should I do when a merge conflict occurs?

Edit the conflicting file to keep the correct final content, remove conflict markers, test, stage the resolved file and commit.
